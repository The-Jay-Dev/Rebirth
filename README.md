# How to play
## Notes
Notes are falling blocks that you must break to score points.
To shatter one, press the matching lane button when it reaches the judgment line. Hit two or more notes without missing to score a combo. The larger the combo, the more points you earn!

## Emotional Capacity
This on-screen bar tracks both your progress through the map and the current state of the game. As you advance, you’ll earn tokens. Each token reveals a hint about upcoming changes to the level.

# Platforms
Rebirth is only available for Windows 64x, as I currently don't have the tools to port it to other systems, but there is a possibility of other ports in the future.

# Installation
The game works right out of the box. Head to releases and download the build, unzip the folder, and run `appRebirth.exe`
